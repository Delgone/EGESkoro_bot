# Telegram-бот: Таймер обратного отсчета до ЕГЭ (@EGESkoro_bot)

Асинхронный Telegram-бот, разработанный для отслеживания оставшегося времени до важных дат. Проект демонстрирует работу с API Telegram, асинхронным программированием на Python и управлением состояниями пользователя (FSM).

## Стек технологий

*   **Язык:** Python 3.10+
*   **Фреймворк:** `aiogram` (асинхронная работа с Telegram Bot API)
*   **Асинхронность:** `asyncio`
*   **Архитектура:** Машина состояний (FSM) для обработки многошаговых диалогов
*   **Деплой:** Удаленный Linux-сервер, управление процессом через `systemd`

## Основной функционал

*   Расчет и отображение точного количества дней до заданных событий.
*   Интерактивное меню и удобная навигация для пользователей.
*   Обработка пользовательского ввода с помощью FSM (конечных автоматов).
*   Бесперебойная работа в фоновом режиме на сервере (настроен автоматический перезапуск службы при сбоях).
